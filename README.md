# Сайт-визитка на 5 секций

## ✨ Что внутри

| Секция | Фишки |
|---|---|
| **Главная** | Анимированные частицы на canvas, typing-эффект, градиентный заголовок, индикатор скролла |
| **Обо мне** | Фото с декоративной рамкой, анимированные прогресс-бары навыков |
| **Услуги** | 6 карточек с SVG-иконками и hover-эффектами |
| **Портфолио** | Сетка проектов с overlay при наведении и зумом картинки |
| **Контакты** | Плавающие лейблы в форме, соцсети с hover-градиентом |

**Общие анимации:** плавный скролл, появление блоков при скролле (IntersectionObserver), подсветка активного пункта меню, адаптивное бургер-меню.

Просто сохрани три файла рядом — и всё заработает. Картинки подтягиваются с `picsum.photos`, иконки — инлайн-SVG, зависимостей нет. 🚀
